# Hope for All project guidance

This repository is a single-page storytelling website focused on empathy, hope, and survivor-led narratives.

## Working principles
- Keep the experience warm, calm, and accessible.
- Prefer semantic HTML and simple, maintainable CSS.
- Preserve responsiveness across mobile, tablet, and desktop layouts.
- Favor readability, strong contrast, and inclusive language.
- Keep the design consistent with the existing editorial and soft-toned brand.

## Constraints
- The current site is a single-file build in `hope-for-all (1).html`.
- Make changes carefully and keep styling tokens consistent with the existing design system.
- Avoid introducing heavy frameworks or build tooling unless explicitly requested.
- Preserve accessibility features like skip links, focus styles, keyboard interaction, and reduced-motion considerations.

## Typical tasks
- Improve storytelling sections and landing-page copy.
- Refine button, form, and navigation interactions.
- Adjust spacing, typography, color tokens, and section layouts.
- Ensure mobile behavior remains polished and easy to navigate.

## Voice and tone
Use compassionate, grounded, and human language. The site should feel hopeful without being overly promotional or clinical.
